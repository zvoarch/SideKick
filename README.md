# SideKick

SideKick is a small Gemini-powered desktop companion for chat, approved apps,
approved folders, tasks, and saved workspaces.

## Run

1. Install the packages listed in `requirements.txt`.
2. Start the app with `python main.py`.
3. Open Settings → General and add your Gemini API key.

Approved applications, folders, and workspaces are managed locally by SideKick.
